# Pocket TTS voice clips

Place optional voice-cloning reference clips here. The bot mounts this directory at `/app/voices`.

Name files after the bias, for example:

- `jungkook.wav`
- `jimin.wav`
- `v.wav`
- `rm.wav`
- `jhope.wav`
- `suga.wav`
- `jin.wav`

Only use clips you have permission to clone. If a clip is missing, `/delulu` uses a built-in
Pocket TTS voice as a stand-in.
