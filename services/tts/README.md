# Siela TTS (Rust)

Drop-in replacement for the Python KittenTTS service (`deploy/podman/tts/server.py`).
Same HTTP contract, same audio pipeline, a fraction of the memory.

- `GET /healthz` → `{"status":"ok"}`
- `POST /synthesize` → buffered 16-bit PCM WAV (`{"text","voice?"}`)
- `POST /synthesize-stream` → chunked WAV with streaming header, same as Python

Pipeline parity with `kittentts==0.8.0` + `phonemizer==3.4.0` + espeak-ng:

1. `chunk_text` (split on `[.!?]+`, 400-char cap, trailing-punctuation rule)
2. espeak-ng FFI (`espeak_TextToPhonemes`, en-us, IPA, `_` separators) — the
   same `libespeak-ng` call phonemizer makes, not the CLI
3. phonemizer's punctuation preserve/restore + `_postprocess_line` replays
4. `basic_english_tokenize` + `TextCleaner` symbol table (generated from the
   wheel source into `src/symbols_generated.rs` — do not hand-edit)
5. `style = voices[voice][min(len(chunk), N-1)]`, `speed = TTS_SPEED × prior`
6. ONNX (`ort`, CPU-only, 1 intra-op thread), trim trailing 5000 samples
7. Stream: `clip × 32767 → i16 LE`; buffered: 16-bit PCM WAV

Concurrency: one global mutex around espeak + session. libespeak-ng keeps
process-global state and is not thread-safe; this also matches the single
voice-channel usage (and the old Python GIL effectively serialized the same way).

## Layout

```
services/tts/
  Cargo.toml / Cargo.lock / build.rs   (links libespeak-ng via pkg-config)
  src/
    main.rs        env config, axum serve
    server.rs      routes
    synthesis.rs   ort session + voices.npz reader
    pipeline.rs    chunking, tokenize, cleaner, voice resolution
    phonemizer.rs  punctuation preserve/restore + postprocess
    espeak.rs      FFI bindings
    symbols_generated.rs  generated from the kittentts wheel (see below)
    wav.rs         WAV encoding
  tests/fixtures.rs  golden tests vs the Python stack
  Containerfile
```

## Development (macOS)

```bash
brew install espeak-ng pkg-config
# model + fixtures live in gitignored .local-tts/ (see below)
MODEL_PATH=$PWD/.local-tts/kitten_tts_nano_v0_8.onnx \
VOICES_PATH=$PWD/.local-tts/voices.npz \
CONFIG_PATH=$PWD/.local-tts/config.json \
PORT=8100 cargo run --release
```

Linux: `apt install libespeak-ng-dev pkg-config`.

## Golden fixtures (parity proof)

`.local-tts/` (repo root, gitignored) holds `fixtures.json` (47 chunks:
phonemes, tokens, input IDs, style rows) generated by the pinned production
Python stack, plus the model files. `cargo test` replays all of it:

- chunk strings, phoneme strings, token lists, input ID arrays: byte-identical
- style rows: sha256-identical, `ref_id` rule included

Regenerate fixtures on the TTS host after any dependency change:

```bash
scp gen.py root@HOST:/tmp/ && ssh root@HOST \
  'podman cp /tmp/gen.py siela-tts:/tmp/gen.py && podman exec siela-tts python3 /tmp/gen.py \
   && podman cp siela-tts:/tmp/fixtures.json /tmp/fixtures.json'
```

(`gen.py` template: build `KittenTTS_1_Onnx` pieces manually per chunk and
dump JSON — chunk, phonemes, `basic_english_tokenize` output, cleaner IDs,
`ref_id`, style-row sha256 + head.)

## Regenerating `symbols_generated.rs`

```bash
# from the kittentts 0.8 wheel:
python3 - <<'EOF'
import re
src = open('kittentts/onnx_model.py', encoding='utf-8').read()
start = src.find('class TextCleaner'); end = src.find('class KittenTTS_1_Onnx')
ns = {}
exec(src[start:end], ns)
d = ns['TextCleaner']().word_index_dictionary
lines = ['pub const SYMBOL_IDS: &[(char, i64)] = &[']
lines += [f"    ('\\u{{{ord(c):X}}}', {i})," for c, i in d.items()]
lines.append('];')
open('services/tts/src/symbols_generated.rs', 'w').write('\n'.join(lines) + '\n')
EOF
```

## Container

```bash
podman build -f services/tts/Containerfile -t localhost/siela-tts-rs:latest .
podman run --rm -p 8001:8000 \
  -e TTS_VOICE=Bruno -e TTS_SPEED=1.0 \
  localhost/siela-tts-rs:latest
```

## Env

| Var | Default | Note |
|---|---|---|
| `MODEL_PATH` | `/models/kitten_tts_nano_v0_8.onnx` | baked into image |
| `VOICES_PATH` | `/models/voices.npz` | baked into image |
| `CONFIG_PATH` | `/models/config.json` | speed priors + voice aliases |
| `TTS_VOICE` | `Bruno` | alias or `expr-voice-*-m/f` |
| `TTS_SPEED` | `1.0` | multiplied by the voice prior (0.8–0.9) |
| `HOST` / `PORT` | `0.0.0.0` / `8000` | |
